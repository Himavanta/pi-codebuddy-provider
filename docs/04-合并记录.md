### 冲突解决

均为「同一位置各自新增」的琐碎冲突，取并集：

**`src/models.ts`（PR#3 × PR#4）** — `remoteModelToPi()` 相邻两行：

```ts
// reasoning：采 PR#4（直读上游字段）
reasoning: m.supportsReasoning === false ? false : m.supportsReasoning === true || detectThinking(m.id),
// input：采 PR#3（直读上游字段）
input: modelSupportsImages(m) ? ["text", "image"] : ["text"],
```

**`src/config.ts`（PR#4 × PR#10）** — `CodeBuddyConfig` 接口，保留全部四个新增字段：

```ts
rewriteLeakedReasoning: boolean // PR#4
rateLimitMaxWaitMs: number // PR#4
rateLimitRetries: number // PR#4
transient400Retries: number // PR#10
```

**`test/models.test.ts`（PR#3 × PR#4 × PR#10）** — 均在文件尾追加用例，全部保留。
