## 风险与注意事项

1. **PR #4 体量大**：新增 `reasoning-leak.ts`（205 行）+ 429 处理，
   实现复杂度高，采纳前需单独审查其正确性。
2. **三个 PR 均基于 `81d2cbf`**：后续若上游复活，rebase 成本会累积。
3. **npm 包名不可用**：`pi-codebuddy-oauth` 的 maintainer 是原维护者，
   无法发布同名包；自用走 git 或本地路径安装即可，不必急于发 npm。
4. **模型缓存不自愈**：已升级用户的 `~/.pi/agent/codebuddy-models-cache.json`
   不会自动更新 `input` 字段（PR #3 作者已指出），需要跑一次 `pi --list-models`
   或重新登录触发发现，才能看到多模态生效。
5. **测试依赖**：阶段 2 起需要 `node_modules`，否则无法验证。
